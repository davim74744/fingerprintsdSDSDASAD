# Raio-X do Navegador

Página única (`index.html`) que mostra tudo o que o navegador expõe: hardware, tela, GPU, codecs, DRM, passkeys, permissões, fontes, APIs da Web e testes com permissão (IP, GPS, câmera, sensores, benchmarks).

Publicado no Cloudflare Pages a partir deste repositório: cada push na branch `main` gera um deploy novo.

Configuração do projeto no Pages: comando de build vazio, pasta de saída `/`.
